# 任务调度模拟器

《数据结构实践》课程实践任务书二 —— 基于队列、优先队列（堆）与线性表的图形界面任务调度模拟系统。

## 一、功能简介

| 模块 | 说明 |
| --- | --- |
| 任务输入与管理 | 界面添加 / 修改 / 删除任务；从 `.csv` / `.json` 加载；表格展示属性与状态；校验重复编号、负数时间、零运行时长等非法输入 |
| 调度算法 | FCFS（先来先服务）、非抢占式优先级调度、RR（时间片轮转，时间片 q 可设） |
| 交互式界面 | 算法选择、时间片设置、开始 / 暂停 / 单步 / 运行到底 / 重置、演示速度调节；实时显示当前时间、运行中任务与就绪队列 |
| 可视化 | 甘特图展示任务执行区间与处理器空闲区间，不同颜色区分任务，红色游标指示当前时刻 |
| 结果统计 | 逐任务周转时间 T、等待时间 W、响应时间 R 及平均值，支持导出 `.csv` |
| 算法对比 | 对同一组任务运行三种算法（含 RR 时间片 1 与 4），对比平均指标 |

## 二、运行环境

- Python 3.8 及以上（开发测试环境为 3.14）
- **零第三方依赖**，仅使用标准库：`tkinter`、`heapq`、`csv`、`json`、`dataclasses`、`collections`
- 若 Python 未随附 Tkinter，请补装对应发行版的 tk 支持包

## 三、启动方法

在项目目录下执行：

```bash
python main.py                        # 启动空界面，手动添加 / 加载任务
python main.py data/example.csv       # 启动并加载任务书示例数据（4 个任务）
python main.py data/mixed.csv         # 长短任务混合
python main.py data/priority_mix.csv  # 优先级混合
python main.py data/same_arrival.csv  # 同时到达
python main.py data/idle_gap.csv      # 分批到达（存在空闲区间）
```

算法自检（无界面，验证 FCFS 与任务书预期一致）：

```bash
python scripts/verify.py
```

## 四、操作说明

1. **准备任务**：点击“加载数据…”读取 CSV/JSON，或点击“添加任务”逐个录入；选中表格行后可“修改 / 删除”。模拟开始后编辑按钮自动禁用，点击“重置”恢复。
2. **选择算法**：在右侧选择 FCFS / 优先级 / RR；选 RR 时在“时间片 q”中输入正整数。
3. **开始 / 暂停 / 单步 / 运行到底**：
   - **开始**：预计算整个调度轨迹，并从头逐单位回放（速度由“演示速度”控制）。
   - **暂停 / 继续**：暂停或恢复回放。
   - **单步**：推进一个模拟时间单位（与任务书定义一致）。
   - **运行到底**：直接跳到最后一个时间单位，展示最终状态。
4. **观察过程**：甘特图显示各任务执行区间与空闲区间，红色游标指向当前时刻；表格用不同底色区分“未到达 / 就绪 / 运行中 / 完成”，右侧实时显示当前时间、运行中任务与就绪队列。
5. **查看结果**：底部“统计结果”给出逐任务与平均的周转 / 等待 / 响应时间，可导出 CSV。
6. **算法对比**：点击“运行对比”，对当前任务集运行 FCFS、优先级、RR(q=1)、RR(q=4)，展示平均指标对比。

> 说明：调度结果由引擎**预先计算**，动画速度只影响回放节奏，不影响任何统计指标；“模拟时间”是抽象时间单位，任务运行 10 个单位不会真的等待 10 秒。

## 五、数据格式

### CSV（任务书示例格式）

```csv
task_id,name,arrival_time,burst_time,priority
T1,任务A,0,5,2
T2,任务B,1,3,1
```

### JSON

```json
{
  "tasks": [
    {"task_id": "T1", "name": "任务A", "arrival_time": 0, "burst_time": 5, "priority": 2}
  ]
}
```

字段约束：`task_id` 唯一、`name` 非空、`arrival_time` 非负整数、`burst_time` 正整数、`priority` 非负整数（数值越大优先级越高）。

## 六、代码结构

| 文件 | 职责 |
| --- | --- |
| `task.py` | 任务模型（`Task`、`TaskState`）与输入校验 |
| `scheduler.py` | 调度引擎（`SimulationEngine`、`Step`、`Segment`、`TaskResult`、`run_comparison`） |
| `data_loader.py` | CSV / JSON 加载与保存、结果导出 |
| `ui.py` | 图形界面（`TaskSchedulerApp`，基于 Tkinter） |
| `main.py` | 程序入口 |
| `scripts/verify.py` | 算法自检脚本（控制台验证 FCFS 与任务书预期一致） |

任务模型 / 调度算法 / 统计分析 / 界面逻辑相互分离，符合任务书“建议设置 `Task`、`Scheduler`、`SimulationEngine`、`UI` 等类”的面向对象设计要求。

## 七、数据文件

| 文件 | 特点 |
| --- | --- |
| `data/example.csv` / `example.json` | 任务书示例数据（4 个任务，默认演示） |
| `data/same_arrival.csv` | 同时到达：所有任务到达时间相同 |
| `data/mixed.csv` | 长短任务混合：1 个长任务 + 4 个短任务 |
| `data/priority_mix.csv` | 优先级混合：不同优先级交错 |
| `data/idle_gap.csv` | 分批到达：两批任务间存在空闲区间 |

## 八、任务书示例数据的实测结果

| 算法 | 时间片 | 平均周转 | 平均等待 | 平均响应 |
| --- | --- | ---: | ---: | ---: |
| FCFS | — | 6.50 | 3.75 | 3.75 |
| 优先级调度 | — | 6.00 | 3.25 | 3.25 |
| RR | 1 | 6.50 | 3.75 | 0.75 |

## 九、网页版（可直接双击打开，无需 Python）

在 `web/` 目录下提供了一套功能完全等价、可直接在浏览器打开的网页版界面：

| 文件 | 说明 |
| --- | --- |
| `web/index.html` | **最终成品**：自包含单文件，内置 5 套任务数据，双击即可在浏览器打开 |
| `web/template.html` | 网页源码（HTML + CSS + JS），数据由占位符注入 |
| `web/build.py` | 构建脚本：把 `data/*.csv` 内嵌进模板，生成 `web/index.html` |
| `web/test.js` | 算法自检（Node 环境）：校验 JS 引擎与桌面版 `scheduler.py` 结果一致 |

- 数据之所以**内嵌**进 HTML，是因为浏览器以 `file://` 协议打开本地文件时，`fetch()` 读取同目录 CSV/JSON 会被同源策略拦截；内嵌后无需任何服务器即可运行。
- 网页版功能与桌面版一致：任务增删改、CSV/JSON 加载与保存、FCFS / 优先级 / RR（时间片可设）、开始 / 暂停 / 单步 / 运行到底 / 重置、速度调节、甘特图与状态实时回放、周转 / 等待 / 响应统计与导出、三种算法对比。
- 重新构建：`python web/build.py`；算法自检：`node web/test.js`。
